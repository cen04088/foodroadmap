# 해커톤 제출 전 점검 — 2026-09-14

대상: https://myfoodroad.up.railway.app/

## 결론

실제 배포 사이트에서 지도·예시 경로 4개·AI 조건 해석·후속 요청·상세·저장 흐름이 동작했다. 다만 식사 예산의 근거에 주류/추가 메뉴가 포함되는 문제가 있어 로컬에서 수정했다. 수정본을 프론트엔드와 백엔드에 배포하고 대표 경로와 AI 추천을 한 번 더 확인한 뒤 제출하는 것을 권장한다. 이번 점검은 푸시·배포를 수행하지 않았다.

## 실제 배포 사이트 확인

| 시나리오 | 관찰 결과 |
|---|---|
| 첫 화면 및 카카오 지도 | 정상, 방송/맛집 API 200, 화면에 12개 프로그램·3,424곳 표시 |
| 서울역 → 강릉역 | 200, 522곳, 약 6.7초 |
| 강남역 → 속초 해수욕장 | 200, 163곳, 약 3.9초 |
| 서울역 → 전주 한옥마을 | 200, 299곳, 약 5.2초 |
| 대전역 → 부산역 | 200, 88곳, 약 3.6초 |
| 한 시간쯤 뒤, 한식으로 2만 원 이하 | 시간 60분·전후 30분·한식·20,000원으로 해석, 3곳 반환 |
| 30분 더 일찍 | 목표 30분으로 수정, 한식/예산 유지 |
| 고기집 빼고 | 제외 조건 추가, 기존 시간/예산 유지 |
| 주차 가능한 곳으로 | 주차를 미확인 조건으로 표시하며 반영하지 못했다고 안내 |
| 메뉴 100원 이하 | 결과 없음 안내, 예산을 임의로 완화하지 않음 |
| 식당 상세 및 저장 | 상세 진입·브라우저 저장·저장 목록 확인 |

실제 AI 호출 5회 모두 HTTP 200, 관찰된 응답 시간 약 1.4~2.0초. 위 시간과 결과 수는 단일 점검 시점 값이며 성능 보장/부하 테스트 결과가 아니다. 브라우저에서 처리되지 않은 JavaScript 오류는 관찰되지 않았다. 건의함 제출, 실제 예약/길찾기 앱 이동, 영상 재생 완료, 크롤러 실행 및 부하 테스트는 수행하지 않았다.

## 로컬 수정

1. 식사 추천 근거에 `능이주`, `사리 추가`가 포함됨: 메뉴명 공백 정규화와 주류·추가 메뉴 제외 목록 보완. `계란찜` 등 기본 식사 추천에서 제외할 곁들임 메뉴도 추가했다. 명시적으로 메뉴를 요청한 경우의 검색은 유지한다.
2. 390px 모바일에서 저장/목록 버튼이 어색하게 줄바꿈됨: 모바일 로고·버튼 크기와 문구 조정. 320/360/390px에서 가로 넘침과 버튼 높이 확인.
3. 모바일 지도 영역의 재검색 버튼과 방송 필터가 겹침: 재검색 버튼을 필터 아래로 배치.
4. 기존 린트의 `any` 타입 오류 18개: 앱에서 사용하는 카카오 SDK 인터페이스와 Window 콜백 타입을 정의하고 연결부에 적용. SDK 초기화 실패도 명시적으로 처리.
5. `NaN`, 무한대, 위경도 범위 초과 입력: 카카오 호출 전 400으로 거절.
6. 이전 턴에서 수정한 긴 식당명 말풍선 줄바꿈도 여전히 미커밋 상태였으므로 함께 배포해야 한다.

## 수정 후 검증

- 백엔드 180개 테스트 통과. 신규 회귀 검증에는 실제 발견된 추가 메뉴와 잘못된 좌표가 포함됨.
- 프론트엔드 39개 테스트 통과.
- 전체 ESLint 및 프로덕션 빌드/TypeScript 통과.
- 로컬 브라우저 테스트: 예시 경로 → AI 추천 → 후속 조건 전달 → 지도 마커/위치 변경 → 상세 왕복 → 전체 목록 전환 → 오류 시 결과 유지 → 요청 취소/초기화 통과. 로컬 UI 검증은 지도/AI 응답 대역을 사용했다.
- 기존 라이브러리의 Vite 설정 경고와 Starlette 사용 중단 예정 경고는 남아 있으나 테스트/빌드 실패는 아니다.

## 제출 표현과 남은 범위

- ‘환각이 불가능’ 대신 ‘AI가 요청을 해석하고 등록된 데이터로 추천 조건을 확인한다’고 설명한다.
- 시간은 우회 미포함 경로상 예상 통과 시점, 예산은 메뉴 한 개 가격이다.
- 메뉴명만으로 모든 식사의 인분 수나 단독 주문 가능 여부를 알 수 없다. 예를 들어 `볶음밥`만 등록되면 단독 식사인지 식후 추가인지 확정할 수 없다. 모든 식당의 식사 총액을 보장하지 않는다.
- 현재 호출 제한은 경로별 횟수·프로세스별 동시 실행 제한이며 서비스 전체 지출 한도나 대규모 부하 대응 검증은 아니다.
- 배포 후 서울역→강릉역에서 ‘한 시간쯤 뒤, 한식으로 2만 원 이하’를 다시 실행해 주류/추가 메뉴 보완이 반영됐는지 확인한다.
